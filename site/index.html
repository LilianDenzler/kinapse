TCR · TCR-pMHC · molecular dynamics

Measure how models capture TCR conformational dynamics.

A modular Python toolkit to load and prep TCR / TCR-pMHC structures, embed sequences, compute docking geometry, quantify structural & MD dynamics, and generate conformer ensembles — each part usable on its own, all composable into full pipelines.

The pipeline

From a PDB & trajectory to a divergence score

Ground-truth MD and a model's predicted ensemble are compared region-by-region (CDR loops) through low-dimensional embeddings and free-energy surfaces.

①

Load & prep

IMGT-renumber, pair α/β chains, slice to CDR/FR regions.

②→③

Embed & geometry

Sequence embeddings; α/β inter-domain docking angles.

④

Analyse

Align, featurize, reduce to 2-D, PMF + Jensen–Shannon divergence.

⑤

Generate

Sample conformers (DiG) and fold them back into a trajectory.

Five modules

Modular by design

Import just what you need — from kinapse.geometry import … pulls in nothing from analysis. Optional heavy deps (torch, PyMOL, MODELLER) load lazily, so import kinapse never breaks.

① structures

Load & prep — the basis

TCR / TCR-pMHC loader: IMGT numbering (ANARCI/ANARCII), interface-based α/β pairing, region slicing, scFv linkers.

  • TCR
  • TCRPairView
  • TrajectoryView
  • pmhc (scaffold)
② embedding

Sequence embedders

Turn chains into sequence representations: FASTA export, MMseqs2-GPU MSAs, OpenFold / Evoformer embeddings.

  • fasta
  • msa
  • evoformer
③ geometry

Docking geometry

The ABangle-style 6-parameter α/β inter-domain geometry — per structure or per MD frame, plus the inverse rebuild.

  • calc_geometry
  • calc_geometry_MD
  • change_geometry
④ analysis

Structure & MD metrics

Align (Kabsch/TMalign/ProFit), CA-dist/coord/dihedral features, PCA·kPCA·TICA·diffmap, trustworthiness, Mantel, PMF, JSD.

  • rmsd_tm
  • embeddings
  • pmf_kde
⑤ generation

Conformer sampling

Drive the DiG diffusion sampler and post-process generated PDBs into an analysable trajectory.

  • dig_runner
  • postprocess

Install

Clones and installs cleanly

CI pip-installs the package and runs the smoke tests on every push. The MD stack is easiest via conda; a pure-pip install works on Linux too.

# conda (recommended)

# full env + package + smoke tests
git clone https://github.com/LilianDenzler/kinapse
cd kinapse && ./setup.sh
conda activate kinapse
kinapse info

# pip (Linux wheels)

pip install "kinapse[numbering,reduce] \
  @ git+https://github.com/LilianDenzler/kinapse"

# or from a clone, editable:
pip install -e ".[numbering,reduce,dev]"
Quickstart

A few lines to a prepped TCR

Load a structure, get its CDR/FR sequences and Fv, compute geometry, then score dynamics.

from kinapse.structures import load_tcr
from kinapse.geometry import calc_tcr_geometry_MD
from kinapse.analysis import run_ca_dist, oriol_analysis

tcr  = load_tcr("1kgc.pdb", traj="1kgc.xtc")   # IMGT-renumber + pair α/β + attach MD
pair = tcr.pairs[0]
print(pair.cdr_fr_sequences())                # {'A_CDR3': 'ATAAVGGFKTI', ...}

df = calc_tcr_geometry_MD("1kgc.xtc", "1kgc.pdb")  # per-frame α/β docking angles
# run_ca_dist(...) / oriol_analysis(...) → 2-D embedding, PMF, Jensen–Shannon divergence

Or from the shell:

kinapse prep 1kgc.pdb --traj 1kgc.xtc --out prep/
kinapse geometry 1kgc.pdb --out geom/
kinapse pipelines            # list the end-to-end workflows
Why kinapse

Built to be used and shared

Independently usable

Five sub-packages; lower layers never import higher ones.

Lazy imports

import kinapse works even without torch, PyMOL or MODELLER.

Config, not hardcoding

Paths resolve from env vars / YAML — no more /mnt/… in scripts.

pip-installable

Core installs from wheels; heavy stacks are optional extras.

CI-tested

Every push installs from a clean checkout and runs the smoke suite.

Nothing lost

All original TCR_Metrics capabilities preserved — just reorganised.
